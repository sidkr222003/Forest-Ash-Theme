# Forest Ash Theme 1.4.0 Feature Pack

This document outlines the differentiating features added in 1.4.0 along with usage notes and commands.

## 1) Focus Mode / Zen Palette

Dim everything except the active function or block, while softening UI contrast for deep focus.

- Command: Forest Ash: Toggle Focus Mode
- Settings:
  - forestAsh.focusMode.enabled (boolean)
  - forestAsh.focusMode.dimOpacity (number, 0.05 - 0.9)

## 2) Circadian Auto-Switching

Automatically switch between a day theme and a night theme based on a timezone-aware schedule.

- Command: Forest Ash: Apply Circadian Theme Now
- Settings:
  - forestAsh.circadian.enabled
  - forestAsh.circadian.dayTheme
  - forestAsh.circadian.nightTheme
  - forestAsh.circadian.dayStart (HH:mm)
  - forestAsh.circadian.nightStart (HH:mm)
  - forestAsh.circadian.timezone (empty uses system)
  - forestAsh.circadian.checkIntervalMinutes

## 3) Language-Specific Accent Overrides

Assign a unique accent color per language using a single config object.

Example:

{"forestAsh.languageAccents":{"python":"#B48EAD","go":"#8FBCBB","rust":"#D08770"}}

## 4) Italic / No-Italic Mode

Toggle italics for the italic-capable token scopes in the active Forest Ash theme.

- Command: Forest Ash: Toggle Italic Mode
- Setting: forestAsh.italicMode.enabled

## 5) High Contrast Boost

Increases contrast for Forest Ash foregrounds and token colors to improve accessibility.

- Command: Forest Ash: High Contrast Boost
- Setting: forestAsh.highContrast.enabled

## 6) Export Palette as CSS Variables

Generate a CSS file with :root variables for the active Forest Ash theme.

- Command: Forest Ash: Export Palette as CSS

## 7) Theme Preview Webview

Preview all 21 Forest Ash themes side-by-side without switching.

- Command: Forest Ash: Preview Themes

## 8) Palette Inspector

Inspect every color token in the active Forest Ash theme with copy-on-click.

- Command: Forest Ash: Show Active Palette

## 9) Custom Theme Sharing

Export or import custom theme JSON files for sharing and collaboration.

Repository sharing:

- Add your JSON file to the share folder and open a PR.

- Commands:
  - Forest Ash: Export Custom Theme
  - Forest Ash: Import Custom Theme

## 10) Theme of the Week

A once-per-week webview that highlights a different Forest Ash theme and mood.

- Command: Forest Ash: Theme of the Week
- Setting: forestAsh.themeOfWeek.enabled

## Notes

- These features are available in the desktop version of VS Code.
- After importing or generating a custom theme, reload the window to register it in the native theme picker.
